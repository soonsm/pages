# 2. 프로젝트
`Action`과 `@notaly` 칩이 달린 줄은 프로젝트 화면에도 표시됩니다.

왼쪽 패널의 `notaly` 프로젝트를 열어보세요.

프로젝트에서는 세 가지 종류의 줄을 모아 볼 수 있습니다.

`Action`은 해야 할 일입니다.
`Waiting`은 누군가의 응답이나 외부 진행을 기다리는 일입니다.
`Decision`은 나중에 다시 확인해야 할 결정입니다.

Action과 Waiting은 완료 상태로 바꾸거나 다시 열 수 있습니다.
